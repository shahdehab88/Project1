# CRUD System

A fully functional CRUD (Create, Read, Update, Delete) web application developed using HTML, CSS, and JavaScript.

The application allows users to input and manage data such as **Name, Email, Salary, and City**, which is dynamically displayed in a table.

**Note:** Data is stored temporarily in the browser memory; refreshing the page will clear all records.

---

## Features
- Add new records (Name, Email, Salary, City)
- Display data in a structured table
- Edit existing records
- Delete records
- Real-time data rendering without page reload

## Usage
1. Open `index.html` in your browser
2. Fill in the form with Name, Email, Salary, and City
3. Click **Submit** to add the data to the table
4. Use **Edit** or **Delete** buttons to modify or remove records
